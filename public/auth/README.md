Sign-in artwork sources:

- `google.png`: Google's official [branding guidelines](https://developers.google.com/identity/branding-guidelines), downloaded from `https://developers.google.com/static/identity/images/g-logo.png`.
- `apple.svg`: the unchanged medium logo path and view box produced by Apple's [Sign in with Apple JS](https://appleid.cdn-apple.com/appleauth/static/jsapi/appleid/1/en_US/appleid.auth.js). Its built-in vertical padding is retained. The logo is displayed only within a configured Sign in with Apple button.

These marks identify the respective authentication providers. They are not ghfind artwork.
